# Hourly Bleed (Free Build)

> Chrome extension that bills your distractions at your hourly rate. Local-only — no license wall, no phone-home.
> Forked from the Web Store build and stripped to remove all licence checks and phone home.

original extension: https://chromewebstore.google.com/detail/hourly-bleed/iepnhnhcopafngccbhfocaggmfnfjpjk

## Why?
Because slop shouldnt be 9 dollars.

## Features
- Local-only - no license checks, no phone home
- No license wall - your $8.99 can stay in your pocket
- No phone home - no analytics, no update checks, no license servers
- No license checks - no license checks, no phone home
- No phone home - no analytics, no update checks, no license servers

## Install

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. **Load unpacked** → select the folder you cloned this repo to
4. Disable the store version if you still have it installed

## Usage

- Set your hourly rate and billable domains in **Settings**
- Popup shows today’s bill, social tax, top offenders, and the last 7 days
- Export CSV from Settings when you want receipts

## Privacy

Everything stays in `chrome.storage` on your machine. No analytics, no update checks, no license servers.
